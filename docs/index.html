Machine Learning Methods

This website presents a collection of Machine Learning notebooks covering the most common supervised learning algorithms. Each notebook follows the same pipeline:

  • Data loading
  • Preprocessing
  • Model training
  • Prediction
  • Evaluation

Notebooks

  • Linear Regression (Regression)
  • Logistic Regression (Classification)
  • K-Nearest Neighbors (Classification)
  • Random Forest (Classification)

This project is intended for educational purposes and demonstrates the differences between regression and classification models, as well as common evaluation metrics.
